# 행사어때 기업 신뢰 콘텐츠 작성 가이드

이 문서는 작성용입니다. 빈 항목이나 예시 문장을 실제 실적으로 게시하지 않습니다.

## 1. 대표 현장사례 3개 준비

단순히 큰 행사 세 개보다 서로 다른 고객의 상황을 보여주는 사례를 선택합니다.
실제로 수행한 것 중 기업 행사, 공공기관 행사, 장비·현장 운영 등 업무 범위가 다른 사례를 권장합니다.

각 사례마다 아래 항목을 준비한 뒤 레퍼런스 → 사례등록 → 현장사례 작성 도우미에 입력합니다.

- 제목: 고객명 공개 가능 여부를 확인한 행사명
- 행사 개요: 종류 / 시기 / 지역·장소 / 참석 규모
- 고객 요청: 고객이 중요하게 생각했던 조건과 어려움
- 담당 범위: 실제 맡은 업무와 고객·외부 협력사의 업무 구분
- 준비 과정: 선택한 배치, 일정, 장비, 진행 방식과 이유
- 현장 운영: 실제 수행한 점검, 리허설, 진행, 철수
- 결과: 확인 가능한 성과나 실제 후기. 수치 근거가 없으면 숫자를 넣지 않기
- 한 줄 요약: 행사 규모와 맡은 업무를 140자 이내로 설명
- 사진: 전체 전경 1장 / 담당 시설·장비 1~2장 / 운영 과정 1~2장
- 사진 설명: 무엇을 보여주는지와 행사어때가 맡은 업무를 사진 바로 아래에 작성

도우미에 작성한 내용은 ‘본문에 추가’를 눌러야 편집기에 반영됩니다.
이미지는 아래 본문 편집기에 추가하고, 최종 저장 전에 내용을 확인하세요.
현재 메인은 공개된 최신 사례 3개를 자동으로 표시합니다. 공개 여부는 관리자 → 설치사례 관리에서 조정합니다.

## 2. 담당자 지원과 현장 운영 — 실제 방식 확인 후 작성

아래 항목을 실제 제공하는 것 / 조건부 제공 / 제공하지 않는 것으로 구분해 주세요.

| 확인할 항목 | 실제 운영 방식 | 적용 조건 | 보여줄 수 있는 근거 |
|---|---|---|---|
| 전담 연락 창구 | | | 담당 역할 소개 |
| 사전 현장 확인 | | | 개인정보를 가린 점검표 |
| 준비 일정 공유 | | | 일정표 일부 |
| 진행 상황 공유 | | | 공유 주기·방식 |
| 장비 점검·리허설 | | | 실제 점검 사진 |
| 현장 책임자 배치 | | | 역할별 업무표 |
| 예비 장비·장애 대응 | | | 적용 행사와 대응 절차 |
| 설치·철수 관리 | | | 작업 순서 |
| 결과 자료·정산 지원 | | | 제공 문서 목록 |

문장 작성 틀:

“[대상 행사/조건]에는 [담당 역할]이 [시점]에 [구체적인 업무]를 진행합니다.
고객 담당자는 [받게 되는 자료 또는 지원]을 확인할 수 있습니다.”

‘완벽’, ‘항상’, ‘전부 직접 수행’처럼 범위를 확정하는 표현보다 실제 절차와 적용 조건을 적어 주세요.
메인의 준비 가이드는 일반적인 확인 사항입니다. 이 문서에 적은 회사 고유의 운영 방식은 확인 후 해당 영역에 반영할 수 있습니다.

## 3. 견적과 상담 이후 진행 과정

### 실제 진행 순서

1. 상담 접수: 접수 경로 / 누가 확인하는지 / 실제 회신 기준
2. 행사 조건 확인: 목적 / 일시 / 장소 / 인원 / 예산 / 필요한 서비스
3. 범위와 견적 협의: 견적서에 표시하는 항목 / 제안 범위 / 수정 방식
4. 진행 확정: 계약·발주 절차 / 고객 준비 자료 / 일정 확정 시점
5. 현장 준비와 운영: 설치 / 점검 / 리허설 / 당일 연락 체계
6. 철수와 정산: 철수 범위 / 결과 자료 / 발행 가능한 서류

실제 순서와 다르면 수정합니다. 제공하지 않는 단계는 삭제합니다.

### 견적에 관한 답변 준비

- 장비·인력·운송·설치·철수 비용을 어떻게 구분하나요?
- 부가세와 출장비는 어디에 표시하나요?
- 운영 시간 연장, 추가 장비, 야간 설치 등은 언제 별도로 계산하나요?
- 고객의 변경 요청은 어떤 방식으로 확인하고 비용을 협의하나요?
- 일정 변경·취소 조건은 어떤 문서로 안내하나요?
- 필요한 계약·견적·정산 서류는 무엇까지 제공하나요?
- 견적 회신 일정은 어느 조건에서 안내할 수 있나요?

### 상담 전 FAQ 답변 준비

- 일정과 장소가 미정이어도 상담할 수 있나요?
- 일부 장비나 운영 인력만 요청할 수 있나요?
- 행사 며칠 전까지 문의해야 하나요?
- 어느 지역에서 진행할 수 있나요?
- 처음 문의할 때 무엇을 준비하면 되나요?

## 게시 전 확인

- 고객명·로고·인물 사진·후기의 공개 가능 여부
- 모든 수치와 실적의 근거
- 직접 수행 업무와 협력사 수행 업무의 구분
- 비용 포함·제외 조건과 회신 시간의 정확성
- 샘플 문장, 대괄호, 미작성 안내문이 실제 본문에 남아 있지 않은지
